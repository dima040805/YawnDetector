# YawnDetector - Система обнаружения зевоты и мониторинга сонливости

## Описание проекта

Приложение iOS для обнаружения зевоты и отслеживания частотно-временных характеристик зевоты у человека с целью определения факта засыпания.

### Основные функции:
- 📹 Захват видеопотока с фронтальной камеры в реальном времени
- 👤 Детекция лица с использованием Vision Framework
- 👄 Анализ landmarks рта для определения зевоты
- 📊 Визуализация статистики и графиков
- ⚠️ Предупреждение о сонливости при превышении порога

## Алгоритм обнаружения зевоты

### Формула Aspect Ratio (AR)

```
AR = высота_рта / ширина_рта = (maxY - minY) / (maxX - minX)
```

Где:
- `minX, maxX` - крайние горизонтальные точки внутренних губ
- `minY, maxY` - крайние вертикальные точки внутренних губ

### Пороговые значения:
- **AR > 0.55** - рот считается широко открытым (потенциальный зевок)
- **Длительность > 0.4 сек** - минимальная продолжительность для засчитывания зевка
- **Дебаунсинг: 1 сек** - минимальный интервал между зевками

### Частотный анализ:
- Используется скользящее окно **60 секунд**
- Частота = количество зевков в окне / размер окна в минутах
- **> 3 зевков/мин** - порог для предупреждения о сонливости

## Требования

- iOS 17.0+
- Xcode 15.0+
- Устройство с фронтальной камерой (не работает в симуляторе)

## Установка и запуск

1. Откройте `YawnDetector.xcodeproj` в Xcode
2. Выберите ваше устройство (iPhone/iPad) в качестве целевого
3. Нажмите Run (Cmd+R)
4. При первом запуске приложение запросит разрешение на использование камеры

> ⚠️ **Важно:** Приложение требует реального устройства с камерой. Симулятор iOS не поддерживает захват видео с камеры.

## Компоненты системы

### YawnDetectorViewModel
Центральный компонент, отвечающий за:
- Обработку кадров через Vision
- Вычисление Aspect Ratio рта
- Анализ временных характеристик зевков
- Подсчёт статистики

### CameraViewController
UIKit контроллер для:
- Настройки AVCaptureSession
- Получения видеопотока
- Передачи кадров на обработку

### FaceLandmarksView
SwiftUI Canvas для отрисовки:
- Зелёной рамки вокруг лица
- Рамки рта (красная при зевке)
- Точек landmarks губ

### StatisticsView
Панель с:
- Счётчиком зевков
- Текущей частотой (зевков/мин)
- Индикатором статуса
- Графиком частоты за 60 сек

## Индикаторы статуса

| Статус | Цвет | Описание |
|--------|------|----------|
| Normal | 🟢 Зелёный | Нормальное состояние |
| Yawning | 🟡 Жёлтый | Активный зевок |
| DROWSINESS ALERT! | 🔴 Красный | Превышен порог сонливости |

## Производительность

- Vision запросы выполняются асинхронно в фоновом потоке
- UI обновляется через @MainActor
- Кадры, не успевшие обработаться, пропускаются
- Таймер графика обновляется каждую секунду
